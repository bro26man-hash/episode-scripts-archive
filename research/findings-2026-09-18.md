**Research date:** September 18, 2026  
**Methodology:** Repository search, star-ranked analysis, open-issue triage across 15+ projects, detailed issue inspection of 15+ high-priority bugs across 6 thematic categories, direct review of community discussion threads on the most-reported issues (SynBioHub #1753, iBioSim #637), and live commit-activity analysis of the two most actively maintained repos.

## Executive Summary

The synthetic biology and biotech software ecosystem is defined by **six interconnected tensions** as of September 2026:

1. **The SynBioHub Swagger API** — The single most impactful open issue. Maintainer `cjmyers` filed issue [#1106](https://github.com/SynBioHub/synbiohub3/issues/1106) on Sep 3, 2026 under the SBH 3.0.0 milestone, assigning it to `pagarap57`. A proper Swagger-documented API would fix iBioSim's broken upload, enable third-party clients, and unlock the v3 migration.

2. **The SynBioHub v1-to-v3 Migration** — v1 is in maintenance mode with 8 open data-integrity issues (milestone SBH 1.6.2), while v3 is a full React+Spring Boot rewrite at only 16 stars. The community hasn't fully adopted the redesign yet.

3. **Interoperability & Integration Friction** — iBioSim can't upload to SynBioHub (#639, #632), OMEX exports miss SBML files (#1753), incremental sync is broken (#1746). The standards exist; the plumbing doesn't.

4. **Desktop Tool Stagnation** — iBioSim has 305+ open issues with cross-platform failures on Mac and Windows 11. GENtle2 has 75+ issues all dating to 2014. The maintainer of iBioSim himself acknowledged the error handling is unhelpful: *"there should be a better error than an exception."*

5. **Modern Language Adoption** — poly (Go, 737 stars) and DnaChisel (Python, 274 stars) are outpacing the aging Java-based tools. SynBioHub v3's React+Spring Boot stack signals the same direction.

6. **The Rise of RNA & Cell-Free Systems** — BioCRNpyler is expanding into TMSE RNA devices (#328) and EnergyTXTL cell-free expression, with an ODEint convergence bug (#337) highlighting the simulation challenges.

## Confirmed Issue Discussions

### SynBioHub v1 #1753 — OMEX Download Missing SBML Attachments

**Reporter:** Gonza10V  
**Date:** Aug 21, 2026  
**Labels:** bug  
**Comments:** 2

**Discussion thread (confirmed from live GitHub comments):**

- **cjmyers (maintainer, Aug 22, 2026):** *"The issue is that Model->source is not followed to find all files. However, the SBML file will come in an OMEX download of the Attachment object or the Collection that has the Attachment as a member."*
- **cjmyers (follow-up, Aug 22, 2026):** *"For SynBioSuite, fixed this by making the SBML file an attachment of the Model object."*

**Analysis:** The root cause is architectural — SBML files are referenced through a `source` pointer on the Model object, but the OMEX export logic doesn't traverse that pointer. The fix used in SynBioSuite was to restructure the data model so SBML files are direct attachments of Model objects. This is a design-level change, not a patch.

### iBioSim #637 — Unable to Generate Models (Jena/Xerces Crash)

**Reporter:** Hatem-synbio  
**Date:** Jan 20, 2025  
**Comments:** 6 (most discussed recent issue)

**Error:**
```
java.lang.NoClassDefFoundError: Could not initialize class org.apache.jena.query.ARQ
Caused by: java.lang.NoClassDefFoundError: org/apache/xerces/util/XMLChar
```

**Discussion thread (confirmed from live GitHub data):**

- **Hatem-synbio:** Was debugging Kenzo's toggle switch model, following the iBioSim tutorial on page 94 for automatic model generation. Shared screenshots and offered the COMBINE archive on Slack.
- **cjmyers (maintainer):** *"I'm pretty sure the issue has to do with trying to create a model using iGEM parts. iGEM parts do not have interaction information, so it is impossible to generate a model. Granted, there should be a better error than an exception. To actually test this better, should use the Cello library."*

**Analysis:** A double failure — (1) iGEM parts lack the interaction data needed for model generation, and (2) iBioSim's error handling crashes with a cryptic Java stack trace instead of telling the user what's wrong. The maintainer himself acknowledges the UX failure.

## Repository Deep Dive Summaries

### SynBioHub v1 (84 Stars)
- **Stack:** Node.js + Java/Maven + OpenLink Virtuoso (RDF triplestore)
- **License:** BSD-2-Clause
- **Development model:** PR-based, CI via Travis + Docker SBOLTestSuite, auto-publish to Docker Hub via GitHub Actions
- **Hosts:** Complete iGEM Registry, enriched *B. subtilis* data, *E. coli* genome features
- **Status:** Maintenance mode (milestone SBH 1.6.2)
- **Live instance:** synbiohub.org | **Dev:** dev.synbiohub.org

### SynBioHub v3 (16 Stars)
- **Stack:** React (Next.js) + Spring Boot (Java 17)
- **License:** BSD-2-Clause
- **Status:** Active development, latest commits Sep 15, 2026
- **Known blocker:** OpenSSL 3 compatibility issue limits dev mode to Mac/Linux
- **Milestones:** SBH 2.0.0 (UX research), SBH 3.0.0 (Swagger API)

### iBioSim (67 Stars)
- **Stack:** Java + libSBML + reb2sac + GeneNet + Yosys
- **Features:** Multi-cellular and spatial modeling, SBML/SBOL support
- **Active devs:** Lukas Buecherl, Pedro Fontanarrosa, Chris Myers
- **2026 commits:** Headless mode stdout fixes, Java SDK gitignore updates, build dependency fixes

### GENtle2 (106 Stars)
- **Stack:** JavaScript (Node.js + Express + Gulp)
- **Description:** Web-based DNA editor; re-think of the original GENtle desktop app
- **Maintainer:** alexandremeunier
- **Status:** Refactor milestones targeting Canvas events, RES/annotation cards, sequence editing

### poly (737 Stars)
- **Language:** Go
- **Description:** Go package for engineering organisms — codon optimization, Gibson Assembly
- **Status:** v1.0 milestone blocked by clone package refactor (#367 → #359)

### DnaChisel (274 Stars)
- **Language:** Python
- **Ecosystem:** EGF Codons suite from Edinburgh Genome Foundry
- **Recent focus:** Chemistry-aware design (UD optimization, GC content), data integrity bugs

### BioCRNpyler (54 Stars)
- **Language:** Python
- **Ecosystem:** BuildACell
- **Features:** SBML chemical reaction networks, TXTL extracts
- **Expansion:** TMSE RNA devices, EnergyTXTL cell-free expression

### Coral (32 Stars)
- **Language:** Python
- **License:** MIT
- **Status:** Health benchmark — only 1 open issue
