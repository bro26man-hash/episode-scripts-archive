# Community Findings Index

This directory contains curated analysis of open issues and community concerns across synthetic biology and biotech software projects on GitHub.

## Files

- **[synbio-tools-survey.md](synbio-tools-survey.md)** — Comprehensive survey of 8 active synbio/biotech repos with open issue analysis, emerging themes, and episode topic recommendations

## How to Use

1. Before recording an episode, scan the latest issues in the relevant repos for currentTalking points
2. Each findings document includes a **"Key takeaway"** section per repo and an **"Emerging Themes"** section across the ecosystem
3. Update periodically as issue trackers evolve — these findings reflect the state at time of writing
